# 🚌 TransLinka

**Smart public transportation platform built with Next.js, offering real-time bus tracking, AR navigation, ticket booking, and user-friendly interfaces.**

## Key Features

* **Admin Panel:** Manage buses, routes, users, bookings, and view analytics. Secure access for authorized admins.
* **Landing Page:** Modern design with app download links, scroll spy navigation, and responsive layout.
* **Authentication:** User registration and login with clean, validated forms.
* **User Dashboard:** Personalized welcome, ticket stats, quick actions (booking, tickets, AR navigation, chatbot), and recent activity feed.
* **Ticket Booking:** Search trips, select seats, pay securely, and get digital tickets with QR codes.
* **My Tickets:** Manage active and past tickets with detailed info and QR code access.
* **AR Navigation:** Real-time bus tracking with camera-based augmented reality guidance optimized for mobile devices.
* **AI Chat Support:** 24/7 chatbot for instant help and FAQs.

## Tech Stack

* Next.js 14 with TypeScript
* Tailwind CSS & Framer Motion for styling and animations
* Lucide React icons, Google Fonts (Inter & Poppins)
* QRCode library for real QR code generation
* React hooks for state management

## Getting Started

1. Clone repo and install dependencies (`npm install`)
2. Run development server (`npm run dev`)
3. Access at [http://localhost:3000](http://localhost:3000)
